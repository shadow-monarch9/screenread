Select it. Alt + Shift + S. Export it.

ContextGrab turns whatever you highlight, from a web table, a chat answer or a spreadsheet, into a clean PDF, DOCX, XLSX or CSV. Local-first, no account.

Download for Windows & macOS View on GitHub

Installers are unsigned, so expect a SmartScreen / Gatekeeper warning on first run. See Install below.

Install

Windows

Download the .exe (or .msi) from the release and run it. SmartScreen may warn because the build is unsigned: choose More info → Run anyway. Hotkey: Alt + Shift + S.

macOS

Download the .dmg and drag the app to Applications. Run xattr -dr com.apple.quarantine /Applications/ContextGrab.app once, then allow it under System Settings → Privacy & Security → Accessibility. Hotkey: Option + Shift + S. Untested: Save as PDF may not work yet.

How it works

  1. Highlight text in any app.
  2. Press Alt + Shift + S. A small popup opens at your cursor.
  3. Pick PDF, DOCX, XLSX or CSV. The recommended one is highlighted. Files land in Downloads.

Features

Smart table detection

Finds tables in pipes, tabs, CSV, aligned columns, Key: Value lines, JSON and HTML tables from web pages.

Styled documents

Markdown becomes a Resume or Memo styled PDF or DOCX, ready to send.

Local first

Parsing and exporting run on your machine. Nothing leaves it by default.

Optional AI extraction

Only when you click the AI button: turn messy prose into a table with a Recruiter, Sales Lead or Financial schema.
